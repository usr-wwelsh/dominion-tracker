Privacy Policy

What we collect

Dominion Tracker only stores what you enter into it: player names, colors, build lists, game scores, and comments. There are no user accounts, no sign-up, and no email addresses collected.

Cookies & tracking

We don't use cookies, analytics, or any third-party trackers. This app doesn't know or care who you are beyond the player name you type in.

A couple of UI preferences (like whether falling-card animations are on, or your preferred score-entry mode) are saved in your browser's localStorage so they persist between visits. That data stays on your device — it's never sent to the server.

Admin credentials

If admin features are enabled on an instance, the username/password you enter are sent once per request over HTTPS to authenticate that action. They are not stored in the browser or logged.

Where your data lives

All game data is stored in a single SQLite database on whichever server is hosting the instance you're using. We don't sync it anywhere else or share it with third parties. Since this project is free and open source, you can also host your own copy and keep everything entirely under your own control.

Questions

This policy covers the software as published. If you're using an instance run by someone else, ask them how they operate their server — this page describes what the app itself does, not any particular deployment.
